# 💎 Divine Designs – Luxury Jewellery Website

Divine Designs is a luxury jewellery website designed to showcase elegant and timeless jewellery collections with a clean, premium, and user-friendly interface.

## 🌐 Live Website

 https://nehagore2.github.io/jewellery-website/

## 📌 Project Overview

The Divine Designs website provides an elegant online jewellery shopping experience where users can explore different jewellery collections and access basic shopping and account features.

The website includes jewellery categories such as Rings, Earrings, Necklaces, and Bracelets along with Wishlist, Cart, Profile, and Contact pages.

## ✨ Features

- 🏠 Home page with luxury jewellery design
- 💍 Rings collection
- ✨ Earrings collection
- 📿 Necklaces collection
- 💎 Bracelets collection
- ❤️ Wishlist functionality
- 🛒 Cart functionality
- 👤 Profile page
- 📩 Contact page
- 📋 Collection page
- 🔗 Navigation menu
- 🦶 Responsive footer with quick links
- ✨ Smooth animations and transitions
- 📱 Responsive design for different screen sizes
- 🎨 Luxury and minimal UI design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Google Fonts
